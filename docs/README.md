## Правила ведения wiki

Подтверждённые решения меняются явно с датой и причиной. Предложения маркируются
как предложения; отсутствие решения не маскируется произвольным значением.
Задачи пока ведутся этим списком. При детализации добавляются владелец, результат
и ссылка на проверку; отдельный трекер и генератор сайта пока не нужны.

Планируемые артефакты: код агента и измерений, протоколы и результаты экспериментов,
исходники и итоговые PDF трёх ВКР, материалы возможных статей.
Каталоги для них появятся вместе с первым содержимым. Формат исходников ВКР
(например, Word или LaTeX) ещё не выбран; формат сдачи рассматривается отдельно в требованиях.
