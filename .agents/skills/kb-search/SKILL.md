# Поиск по wiki

Из корня репозитория пересобери локальный индекс, если Markdown менялся:

```sh
python3 .claude/skills/kb-search/gitmark.py index
python3 .claude/skills/kb-search/gitmark.py search "<запрос>" -k 8
```

Индекс `.gitmark/` — производный, не источник решений. Поиск по умолчанию
не включает исторические `plan` и `report`; для прошлого замысла добавь
`--scope all`. Открой наиболее подходящие документы инструментом чтения,
сверь контекст и процитируй их с путями и строками. Если речь о текущих
задачах или подтверждённых ограничениях, начни с
[главной wiki](../../../docs/gitmark/README.md).
