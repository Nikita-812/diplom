# Граф документов wiki

Из корня репозитория запусти:

```sh
python3 .claude/skills/kb-search/graph.py
```

Скрипт читает Markdown напрямую и создаёт игнорируемый Git файл
`artifacts/kb-graph.html` (каталог создаётся автоматически). Проверь число
документов и связей в выводе, предложи открыть HTML в браузере и дай ссылку
на полученный файл; отдельный просмотр файла удобен, если доступна карточка
артефакта. Для другого места вывода допускается `-o <путь>`, но сначала
убедись, что не перезаписываешь чужой файл. Значения и ограничения графа —
в [онтологии](../../../docs/gitmark/ontology.md).
