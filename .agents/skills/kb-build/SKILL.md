# Проверить и индексировать wiki

1. Проверь `git status`, прочитай [индекс wiki](../../../docs/gitmark/README.md)
   и [онтологию](../../../docs/gitmark/ontology.md). Из корня репозитория выполни:

   ```sh
   python3 .claude/skills/kb-search/gitmark.py index
   python3 .claude/skills/kb-search/gitmark.py stat
   python3 .claude/skills/kb-search/gitmark.py lint --strict
   .venv/bin/mkdocs build --strict --site-dir /tmp/diplom-site
   ```

2. Если пользователь указал область, сопоставь имеющиеся документы и исходники
   только в ней. Опиши пробелы с проверяемыми источниками. Предлагай изменение
   существующей wiki; новые документы — только под конкретную потребность.
3. Сообщи количество документов, результат проверок и что осталось непокрытым.
   Индекс `.gitmark/` производный и игнорируется Git; этот навык не означает
   автоматического сочинения документации или запуска исследовательского агента.
